## 跨端与安全

- [ ] 同一 Wi-Fi 通过 mDNS + 指纹锁定 HTTPS 成功。
- [ ] 局域网失败时通过 `https://<host>.ts.net/order-capture` 成功。
- [ ] Mac 离线时手机加密排队，不出现截图缓存。
- [ ] 重复发送和服务重启不生成第二篇 Inbox 笔记。
- [ ] 地址、手机号、支付账号、快递单号在手机预览和 Inbox 中均不可见。
- [ ] `FLAG_SECURE` 页面提示无法采集，不观察到绕过行为。
- [ ] 复制 Markdown、Inbox、实体草稿、实体提交互不影响。
- [ ] 新增 Tailscale 路径后，原 CouchDB `/` 代理和 LiveSync 验证仍正常。
- [ ] 新建单件/批次的 ULID、日期、订单行价格、订单数量和未知现场数量符合实体 schema。
